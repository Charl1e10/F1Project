# F1 Project - Purple Sector Data Analysis Website
This F1 project will hopefully become a website which has lots of F1 data features for watchers and specialists, some of the features being:
- Fastest lap time which is simulated using old telemetry data and possibly using machine learning to improve the model
- Old races visual to watch old races from a top down track view
- Driver tab to see stats about a driver
- Pit stop calculator for seeing when a driver would come out if they pitted now
- Insights to who knows what tracks the best and the podium winners of that track
- Championship details as well as the calendar
- Adding your lap time from the F1 games to compare to other users
- Live data
